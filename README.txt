# Safe & Sound — Mini Website

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. Press "Listen to the song" or "Open on Anghami".
4. The buttons open the Anghami link provided for the song.

Important:
The Anghami share URL is a webpage/share link, not a direct MP3 file. A normal HTML `<audio>` element cannot reliably play that share page as an audio source, so this version opens the song on Anghami when the user presses the button.
